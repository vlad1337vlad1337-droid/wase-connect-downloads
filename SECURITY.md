# Безопасность загрузок

Единственный каталог GitHub-загрузок этого проекта: https://github.com/vlad1337vlad1337-droid/wase-connect-downloads/releases. Проверяйте точное имя владельца и контрольные суммы выпуска.

Стабильные файлы публикуются после применимых проверок подписи и установки. Не отправляйте ссылки подписок, токены, UUID, пароли или персональные журналы в публичные Issues.

Для уязвимостей включён [приватный канал GitHub Security Advisories](https://github.com/vlad1337vlad1337-droid/wase-connect-downloads/security/advisories/new). Опишите проблему, затронутые версии и безопасные шаги воспроизведения. Сообщение не появится в публичных Issues. Действующие пароли и ссылки подписок не нужны и в приватном отчёте.
