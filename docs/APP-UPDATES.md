# Обновления приложения

Функция добавлена во внутреннюю версию 2.1.16. Публичный стабильный выпуск и его установщики ещё не опубликованы.

В разделе «Настройки → Обновление приложения» можно проверить наличие новой версии, отменить проверку или повторить её после ошибки. При обычном запуске первая фоновая проверка начинается не раньше минуты после старта. Следующие автоматические проверки выполняются не чаще раза в сутки; после ошибок интервал увеличивается. Таймер работает, пока запущено приложение. Ошибка проверки не мешает пользоваться клиентом.

Результат виден в настройках. Если для вашей платформы принят публичный выпуск, там появятся номер версии и кнопка «Открыть страницу выпуска». По нажатию открывается официальная страница GitHub; скачивание и установка выполняются вручную. Отдельного системного push-уведомления и автоматического установщика в этой версии нет.

Сообщение «Публичный выпуск готовится» означает, что через этот канал пока нельзя получить принятое обновление. Оно не означает, что установленная версия самая новая. Обновление подписок — отдельная функция: оно меняет список серверов и сведения провайдера, а не саму программу.

В сборках для магазинов внешний каталог отключён. Обновления нужно проверять средствами соответствующего магазина; встроенная интеграция с его API ещё не реализована. Это не объявление доступности Wase в App Store, Google Play или Microsoft Store. Неподписанная сборка iOS не является установщиком для iPhone.

Каталог должен описывать принятый stable-выпуск для нужной платформы и архитектуры. Приватные черновики и неподписанные тестовые пакеты не становятся предложением обновления. Сведения издателя в каталоге не заменяют проверку подписи самого установщика. Правила безопасной установки и ограничения указаны в [руководстве](INSTALL.md) и [совместимости](COMPATIBILITY.md).

Проверка не передаёт подписки, серверы, установленную версию, ID устройства или логины. Запрашивается публичный HTTPS-каталог без cookies и credentials; настройки сети не меняются. Выбор системного прокси сохраняется, но сохранённые логин, пароль и специальные заголовки прокси не передаются. Если для сети нужна авторизация прокси, проверка завершится ошибкой.
