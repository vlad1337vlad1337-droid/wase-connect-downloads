# Совместимость

Публичный стабильный выпуск ещё готовится. Требования ниже — целевые параметры уже собираемых пакетов, а не подтверждение испытаний каждой комбинации устройства и ОС.

| Платформа | Требования | Текущий статус |
|---|---|---|
| macOS | 13+, Apple Silicon / Intel | Локальные испытания; нужен подписанный проверенный DMG |
| Windows | 10 1809+ / 11, x64 | Общий UI проверен под Wine; настоящие Windows испытания впереди |
| Android | 9+, ARM64 / ARMv7 | ARM64-эмулятор проверен; физические устройства впереди |
| Android TV / Google TV | 9+, подходящий ARM процессор | Нужна проверка телевизора и пульта |
| iOS / iPadOS | 17+ | Компиляция выполнена; подписанного пользовательского пакета нет |
| tvOS | Уточняется | Клиент в разработке |

Импорт и фактическая поддержка протокола зависят от платформы и конфигурации. Не все форматы подписок взаимозаменяемы. Неподдерживаемые ноды не должны представляться рабочими.

Системный прокси обслуживает программы с поддержкой прокси. Полный туннель зависит от платформенной VPN-службы и правил исключений. Kill Switch — отдельная опция; он не включается как обязательная настройка для всех пользователей.
