# Установка

Стабильные установщики ещё не опубликованы. Эта страница описывает ожидаемый путь установки принятого выпуска, а не инструкцию обхода защиты системы.

## Mac

Откройте DMG из Releases, перетащите Wase Connect в Applications и запустите оттуда. В принятом выпуске для открытия не нужны Terminal, удаление quarantine или отключение Gatekeeper. Стандартное подтверждение запуска загруженной программы macOS может показывать.

Настройка встроенной системной службы для туннеля отдельно требует разрешения администратора. Это системное действие и не равно ошибке открытия программы. Текущая реализация использует службу и не добавляет профиль Apple Network Extension в системный список VPN.

Если macOS сообщает, что файл повреждён или запуск запрещён, не меняйте настройки защиты ради установки. Проверьте версию и SHA-256 и сообщите об ошибке через Issues.

## Windows

Откройте EXE из Releases. Для системной VPN-службы может потребоваться разрешение администратора. До появления принятого выпуска скачивать установщик здесь пока нечего.

## Android / Android TV / Google TV

Установите APK из Releases и подтвердите стандартное разрешение Android на VPN при первом подключении. Android может потребовать разрешение на установку приложений из выбранного источника. На телевизоре используйте файл с явно указанной поддержкой вашей архитектуры.

## iPhone / iPad / Apple TV

Ссылки на App Store или TestFlight появятся после выпуска. Архивы разработчика и неподписанные IPA не предназначены для обычной установки.

## После установки

Добавьте свою поддерживаемую подписку, выберите автоматический сервер или локацию и нажмите на маскота. Сам клиент не выдаёт доступ к серверам без подписки. Возможности и правила вашего провайдера могут отличаться.
