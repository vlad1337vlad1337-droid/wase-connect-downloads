# Zapret для Windows в Wase Connect

Документ описывает реализацию внутреннего Windows-обновления 2.1.9. Публичный стабильный установщик ещё не опубликован; текущий статус — в [матрице совместимости](COMPATIBILITY.md).

В разделе «Расширенные → Zapret для Windows» можно проверить пакет Flowseal, запустить выбранную стратегию, подобрать её автоматически или остановить. Выбор папки или стратегии ничего не запускает. Для работы нужна установленная служба Wase той же версии.

## Начало работы

1. Нажмите «Скачать Flowseal 1.10.3». Распакуйте ZIP в новую локальную папку; прежнюю папку с вашими изменениями сохраните отдельно.
2. Нажмите «Выбрать папку» и выберите папку с `service.bat`, `bin` и `lists`. Дождитесь сообщения «Flowseal … · файлы проверены».
3. Отключите VPN Wase. Если вы сами запускали другую копию Zapret, завершите её через ту программу. Wase не определяет автоматически все сторонние VPN.
4. Проверьте безопасный DNS по [официальной инструкции Flowseal](https://github.com/Flowseal/zapret-discord-youtube/blob/865da4f4c3659523bf79bc6edf0446e7d7969614/README.md). Настройки DNS Windows и браузера этот раздел Wase не меняет.
5. Нажмите «Подобрать и включить» либо выберите стратегию и нажмите «Запустить». Подтвердите использование сетевого драйвера WinDivert в окне Wase. Не запускайте Flowseal BAT или PowerShell отдельно: кнопки Wase сами управляют своей проверенной копией.
6. Если появится «Использовать проверенный драйвер», прочитайте отдельное подтверждение. «Разрешить и продолжить» разрешает использовать уже загруженный проверенный WinDivert в этом сеансе. «Отмена» сохраняет отказ запуска. Внешняя служба не переустанавливается и не останавливается.
7. Проверьте приложение Discord, голосовой чат и видео YouTube. Для завершения нажмите «Остановить Zapret». Закрытие Wase также останавливает запущенный им процесс. Автозапуск при входе в Windows не включается.

«Пакет и сведения» показывает версию и отличия файлов. «Результаты подбора» показывает текущие проверки сайтов. «Помощь» открывает краткую инструкцию.

## Поддерживаемые пакеты

| Официальный выпуск Flowseal | Стратегий |
|---|---:|
| [1.10.3](https://github.com/Flowseal/zapret-discord-youtube/releases/tag/1.10.3) | 22 |
| [1.10.2](https://github.com/Flowseal/zapret-discord-youtube/releases/tag/1.10.2) | 22 |
| [1.10.1](https://github.com/Flowseal/zapret-discord-youtube/releases/tag/1.10.1) | 21 |

Wase распознаёт точный выпуск по файлам, а не по названию папки. Для этих версий исполняемые компоненты одинаковы; списки и стратегии проверяются отдельно. С 2.1.9 допускаются также три точных стандартных шаблона, созданных Flowseal: `lists/ipset-exclude-user.txt`, `lists/list-general-user.txt` и `lists/list-exclude-user.txt` (LF/CRLF). Добавленные домены, изменённые списки, неизвестные файлы и пакеты вне каталога не получают разрешение на запуск. Личные списки не удаляются и не переписываются. Если папка отличается, распакуйте чистый поддерживаемый выпуск в новую папку.

1.10.3 — основной проверенный выпуск Wase 2.1.9. Это не результат фонового поиска обновлений. «Все выпуски Flowseal» открывает [официальный каталог](https://github.com/Flowseal/zapret-discord-youtube/releases). Wase не обновляет Flowseal автоматически и не разрешает неизвестные версии из ветки `main`. Новые версии добавляются после проверки файлов и аргументов в обновлении Wase.

## Что означает успешный автоподбор

Сначала Wase проверяет сайты без запуска Zapret, затем перебирает стратегии выбранного выпуска. В 2.1.9 успешные исходные запросы больше не отменяют нажатое «Подобрать и включить». Первая стратегия, при которой прошли обе HTTPS-проверки, остаётся запущенной. Неуспешный процесс останавливается перед следующим; «Остановить Zapret» отменяет перебор.

Проверяются ответ Discord на `https://discord.com/api/v9/experiments` и ответ YouTube на `https://www.youtube.com/generate_204`. Для пары запросов установлен предел 6,5 секунды после короткого ожидания запуска. Полный перебор может занять несколько минут.

Результат подтверждает только HTTPS-доступ к этим адресам. Он не подтверждает голосовой UDP/RTC, работу приложения Discord, качество видео или другую сеть. Если сайт доступен, а приложение Discord нет, сравните результат с [веб-версией Discord](https://discord.com/app) и попробуйте другую проверенную стратегию. Сбой DNS требует отдельной проверки DNS; переименование папки со стратегией его не исправляет.

## Если запуск заблокирован

| Ситуация | Что сделать |
|---|---|
| Папка отличается | Откройте «Пакет и сведения» и выберите чистую папку поддерживаемого выпуска. |
| Служба Wase недоступна или версия отличается | Нажмите «Проверить службу». При сохранении ошибки обновите или восстановите Wase штатным установщиком. |
| Подтверждена другая копия Zapret | Завершите известную вам копию через её программу. Wase показывает имя/PID и не закрывает чужой процесс сама. |
| Загружен проверенный WinDivert | Прочитайте отдельное согласие на совместное использование. Отмена ничего не запускает. |
| Происхождение драйвера не подтверждено | Это не доказательство работающего Zapret. Если известна программа, загрузившая драйвер, завершите её штатно. После сохранения работы можно перезагрузить Windows и проверить её автозапуск. При повторном отказе сохраните код и этап проверки из сведений. |
| Непроверенная запись WinDivert остановлена | Это не работающий процесс. Wase не запускает и не удаляет неизвестную запись. Управляйте старой установкой через её известный установщик или программу. |
| Код `driver-stage-missing`: драйвер от предыдущего запуска Wase | Сохраните работу и один раз перезагрузите Windows, затем снова выберите проверенную папку и запустите подбор. Если ошибка осталась, сохраните её код и этап из сведений; Wase не перезагружает компьютер сама. |
| Драйвер удаляется или меняет состояние | Дождитесь завершения действия Windows и повторите запуск. Остановить собственный подбор Wase можно в любой момент. |
| Windows отказала в чтении или проверка подписи не прошла | Сохраните код Windows, код WinVerifyTrust, этап и причину, если они показаны. Отказ не означает, что найдена другая копия; проверки защиты сохраняются. |

Исходная папка в «Загрузках» допустима: служба копирует проверенные байты в своё защищённое хранилище. Уже загруженный драйвер из файла, который может изменять обычный пользователь, для совместной работы не допускается. Это разные проверки; смена названия папки не подтверждает происхождение драйвера.

`Check Status` в Flowseal читает состояние. `Run Diagnostics` способен менять TCP timestamps и останавливать/удалять службы; это не пассивная проверка, и Wase не выполняет её автоматически.

## Связь с Flowseal

[Официальный README](https://github.com/Flowseal/zapret-discord-youtube/blob/865da4f4c3659523bf79bc6edf0446e7d7969614/README.md) описывает безопасный DNS, стратегии и дополнительные команды `service.bat`. Wase использует собственные кнопки и не выполняет это меню. Он не меняет hosts, глобальные параметры TCP, антивирус, игровые фильтры или ваши списки; не очищает кэш Discord и не импортирует отчёты Standard tests/DPI checkers.

Пользовательский бот для установки или автоподбора в этом README не описан. [GitHub-бот проекта](https://github.com/Flowseal/zapret-discord-youtube/blob/865da4f4c3659523bf79bc6edf0446e7d7969614/.github/workflows/comment.yml) оставляет справочные ответы в issues и не управляет Windows. Wase с ботом не интегрирован; пакеты следует брать по официальным ссылкам выше.

## Границы проверки

Wase запускает свою проверенную защищённую копию. Пользовательские BAT/PowerShell не исполняются. Для совместного использования внешнего WinDivert требуются проверенные байты, подпись, защищённый путь, работающее состояние и отдельное согласие. Чужие службы приложение не останавливает и не удаляет.

Инструкция описывает исходники Wase 2.1.9; подтверждение публикации конкретного EXE выполняется отдельно. На одноразовой Windows Server 2022 подтверждены подпись WinDivert, запуск/остановка, повторный запуск и смена стратегии с фильтром false. Это не проверка реального трафика: Discord voice, YouTube и пользовательская установка требуют отдельной приёмки. Статус готовности конкретного установщика определяется отдельно.
