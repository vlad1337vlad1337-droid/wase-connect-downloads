# Сторонние компоненты

Маскоты в оформлении этой страницы созданы на основе [Blobatar](https://github.com/Alain00/blobatar), MIT; [текст лицензии](assets/Blobatar-LICENSE.txt).

Приложение использует сторонние компоненты, в том числе Qt (LGPL/GPL в зависимости от модуля), sing-box (GPL), Xray (MPL), AmneziaWG, flag-icons, Lucide и Radix Colors. Их права и обязательства сохраняются независимо от того, что исходники оригинального клиента приватны.

К каждому публичному бинарному выпуску должны быть приложены применимые лицензии, точные версии, исходники соответствующих компонентов/изменений и сведения для relinking там, где этого требует лицензия. До закрытия этих требований стабильные бинарные выпуски здесь не публикуются.

Этот репозиторий не выдаёт себя за исходный код приложения. Автоматический архив Source code содержит только файлы страницы загрузок.
